What it does, and why it exists

Most repetitive work never gets automated because nobody has hard numbers on how much time it actually costs. AutoProcess Twin builds those numbers automatically: it records which app and window title is active every 20 seconds, groups the recurring ones into patterns, and turns that into a monthly picture of where manual work is eating hours — so a manager can decide where automation or AI actually pays off, instead of guessing.

What's inside

Pattern detection, not raw logging

Groups recurring window activity (same CRM screen, different customer) into named patterns automatically — no manual tagging.

Automation recommendations, with a confidence score

Each pattern above the noise threshold (20+ minutes, 4+ repeats) gets a plain-language suggestion for where a tool, AI, or automation could take over, plus a 0-100 confidence score (high/medium/low) based on day-coverage and how often it repeats — not an AI/ML guess, just two honest ratios so you know which suggestions to trust first.

Monthly dashboard, exportable

A local dashboard with a category time-breakdown (CRM, invoicing, support, files, mail, meetings, and more) showing where the hours actually go, trend arrows (up/down/new), and a one-click HTML/CSV report you can send to a manager — no cloud account needed.

Privacy filter you control

Exclude specific apps or keyword-matched window titles (banking, password managers, specific clients) — enforced before anything is written to disk.

No autopilot, on purpose

The tool never sends emails, touches your CRM, or takes any action on its own. It only observes and recommends — every action stays with a human.

Runs entirely on your PC

SQLite database on your machine, no cloud sync, no account. An optional AI summary feature is off by default and only sends aggregated numbers, never screenshots or raw text.

Automatic updates

The app checks GitHub for a newer version shortly after launch (at most once per session) and lets you know with a quiet notification — it never re-downloads or reinstalls anything for you, and it never phones home for anything besides that one version check. You can turn the check off in Settings, or trigger it manually from the Help tab. The source of truth for every release is github.com/ofirshudari1-ship-it/autoprocesstwin.

Questions people actually ask

Is my data sent anywhere, to the cloud or to Claude/OpenAI?

No, by default. Everything — window titles, screenshots, OCR text, the pattern database — stays in a local SQLite file on your computer. There is one optional, off-by-default "AI summary" feature; if you turn it on and configure an API key yourself, it sends only aggregated numbers (category, app name, minutes, occurrence count) to the endpoint you configured — never screenshots, never raw window titles, never the API key of anyone but you.

Does it need admin rights to install?

No. It installs to your user profile (%LocalAppData%\Programs\AutoProcessTwin) and never touches Program Files or the system-wide registry, so no UAC prompt appears. This is a deliberate choice — the tool needs to observe your own logged-in session, which a per-user install can do without elevation; installing to Program Files would require admin rights for zero added benefit here.

Does it record my keystrokes or passwords?

No keystroke logging exists in this tool, by design — that would effectively be a keylogger and isn't needed to see what work repeats. It captures the active window's title and a screenshot on a timer, with a privacy filter you configure to exclude specific apps (like password managers) or keyword-matched titles before anything is saved.

Can it act automatically — send emails, update my CRM, close deals?

No. This is intentionally report-only today: it detects patterns and recommends, it never executes anything on its own. An "Autopilot" mode was in the original concept but was deliberately not built, and won't be built to run unsupervised — every action a user takes based on a recommendation stays a manual decision.

What happens to old recordings?

Data older than the retention window you set (30 days by default) is purged automatically, including its screenshots.

How do I uninstall it, and does it clean up fully?

Windows Settings → Apps → AutoProcess Twin → Uninstall. It removes the installed files, shortcuts, and its registry entry; you'll be asked separately whether to also delete your recorded data.

Does it update itself automatically?

No — same report-only principle as pattern detection. A few seconds after launch, once per session, the app makes a single check against the project's public GitHub Releases page. If a newer version is tagged there, you get a quiet, dismissible notification linking to the release notes — nothing is downloaded or installed without you clicking through and choosing to. Any network failure is silent and never interrupts the app.

Privacy, in plain terms

100% local by default

AutoProcess Twin observes activity on the computer it's installed on, in order to detect repeated manual work. Here is exactly what that means in practice:

  • Every ~20 seconds, it records the active window's application name and title, and a screenshot of the screen.
  • A privacy filter (which you configure) excludes specific applications or keyword-matched window titles — for example a password manager, a banking app, or a specific client name — before anything is written to the local database.
  • Basic redaction attempts to blank out patterns that look like credit-card or national-ID numbers picked up by OCR. This is best-effort, not a guarantee — don't rely on it as your only safeguard for highly sensitive screens; add them to the exclusion list instead.
  • All data — the SQLite database, screenshots, and generated reports — stays on the local disk. Nothing is uploaded, synced, or sent to any server, by default.
  • An optional AI-summary feature is off by default. If a user enables it and supplies their own API key, only aggregated numeric data (category, app, minutes, occurrence count, trend) is sent to the endpoint configured — never a screenshot, never raw window-title text, never keystrokes.
  • Anyone who appears on the recorded user's screen (colleagues, clients, in shared apps) is captured only as part of that screenshot/window-title record — the tool has no separate mechanism for recognizing or tracking third parties, and the same exclusion rules apply.
  • Retention is configurable (30 days by default) and enforced automatically — old recordings and their screenshots are deleted, not just hidden.
